# AGENTS.md — Chat-analytics (AEVO)

## Цель и границы
Регулярный конвейер аналитики русскоязычных Telegram-сообществ Таиланда (сбор, дедупликация, когортный анализ пользователей, сквозная идентификация, динамика интересов, классификация тематик).

## Канонический путь
- `/home/user/projects/AEVO/Chat-analytics`

## Источники правды
- Исходные выгрузки: `data/raw/` (Telegram JSON dumps)
- Аналитическая база и витрины данных: `data/processed/` (DuckDB / Parquet)
- Задачи и статус: `tasks/TASKS.md`
- Архитектура и дизайн: `docs/ARCHITECTURE.md`

## Стек и инструменты
- **Python 3.14 / DuckDB / Polars**: быстрый локальный ETL и аналитические срезы миллионов сообщений.
- **LAYA (`NandhaKishorM/laya`)**: локальная легковесная модель для System 1 классификации (темы, интенты, scoring, Q&A) на RTX 3060 (12GB VRAM).
- **Node.js (опционально `laya-ts`)**: клиентские скрипты или интеграция при необходимости.

## Обязательные правила и ограничения
1. Не хранить сырые выгрузки (JSON) и файлы базы данных (DuckDB/Parquet) в Git (строго в `.gitignore`).
2. Любые пользовательские данные обрабатывать конфиденциально: в документах и отчетах оперировать агрегатами или маскированными ID.
3. Не выполнять push/commit в глобальный репозиторий без проверки.
4. Все расчеты должны быть воспроизводимыми и поддерживать инкрементальное еженедельное обновление без дублирования записей.
