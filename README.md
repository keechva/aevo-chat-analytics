# Chat-analytics (AEVO): Платформа продуктовых инсайтов

Система регулярной аналитики аудитории Telegram-сообществ по Таиланду и поиска продуктовых гипотез/болей на базе **DuckDB**, модели **LAYA (`NandhaKishorM/laya`)** и веб-интерфейса на **FastAPI + Vue 3**.

## Текущий статус
- **Статус**: `active`
- База DuckDB: **239 992 сообщения**, **23 164 участника** из 4 сообществ.
- Локальная модель LAYA развернута на GPU **NVIDIA GeForce RTX 3060**.
- Веб-приложение запущено и доступно: **http://localhost:8000**.

## Возможности веб-интерфейса
1. **Дашборд болей (Dashboard)**:
   - Обзор ключевых метрик аудитории, распределение по темам и типам сигналов.
   - Очаги острых болей вокруг визовых изменений DTV (15.09.2026), отказов банков и страховых.
2. **Лента продуктовых инсайтов (Signals Feed)**:
   - Фильтры по тематике (Визы, Деньги, Жилье, Транспорт, Медицина).
   - Фильтр по типам сигналов: `Жалобы/боль`, `Поиск платной помощи (Buy)`, `Сложные вопросы`.
   - Фильтр по шкале боли (от 0.0 до 3.0) и полнотекстовый поиск.
   - Кнопка **«+ Сформировать гипотезу»** прямо из сообщения.
   - Ручная смена тегов сообщений экспертом (Human-in-the-loop).
3. **Бэклог продуктовых гипотез (Hypotheses)**:
   - Карточки сформулированных идей продуктов/сервисов с описанием проблемы, сегмента и подтверждающими цитатами.
4. **Правила и разметка LAYA (Rules & Settings)**:
   - Просмотр и редактирование активных правил и ключевых слов.
   - Запуск пакетной LAYA-разметки на GPU прямо из интерфейса.

## Быстрый запуск

```bash
# Запуск веб-сервера (FastAPI + UI)
./run_app.py
# Приложение откроется на http://localhost:8000
```
